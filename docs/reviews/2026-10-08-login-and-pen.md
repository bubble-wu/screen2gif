# 单页设置、自启动与 pen.dev

## 本轮变更

- 继续使用一个设置页，无页签。顺序为输出位置、画质与体积、快捷键、文本水印、启动与提示音；「导出后在访达中显示 GIF」归到输出位置。
- 水印关闭时收起效果预览，保留文本输入。窗口宽 530 pt，高度不超过 740 pt，并适配屏幕可用高度；较长内容纵向滚动。
- 仅取消打开「设置…」的 `⌘,`，保留录制全屏、框选、停止三个全局快捷键及配置。
- 使用 `SMAppService.mainApp` 管理自启动。在首次启动新版时默认注册；只尝试一次，之后尊重用户在 app 或系统设置中的关闭操作。
- 开关展示系统真实状态。待批准、找不到登录项、注册或注销失败有对应反馈。设置页打开和 app 重新激活时刷新状态。
- 测试和离屏预览使用内存偏好与模拟登录项，不替用户修改系统登录项。

## pen.dev 交付

- 文件：`design/settings.pen`，通过 pen.dev UI 新建与保存，再通过 MCP 生成可编辑图层；未操作原有学习指南。
- 两个完整单页状态：「设置 · 默认状态（单页完整内容）」和「设置 · 水印开启（单页完整内容）」。它们是同一页面的状态，不是两个产品页面或页签。
- 颜色与字体使用变量；控件、文字、分组是独立图层。
- PNG 预览：`design/previews/bi8Au.png` 和 `design/previews/FUkUg.png`。
- 设计稿展示全长内容，原生 app 在固定窗口内滚动；系统原生控件的具体外观由 macOS 决定。
