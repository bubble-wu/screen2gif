# 1.5.0 统一设置与画质

用户指出旧「输出位置：桌面…」点击后的实际体验是打开文件夹，无法明确完成目录设置。此前仅根据菜单名称判断可设置，未经过点击验证。

## 变更

- 菜单统一为「设置…」（⌘,），包含输出位置、画质与体积、快捷键、录制与导出偏好。
- 输出位置中「更改输出文件夹…」使用附着于设置窗口的 NSOpenPanel，只能选文件夹；点「选为输出文件夹」确认后保存，取消不修改。另设「在访达中显示」按钮。
- 保留原 UserDefaults 的 outputDirectory 键，旧目录不丢失。质量与两个开关单独持久化。
- 清晰优先：原始像素、20 fps、最多 600 关键帧、高变化灵敏度；均衡：1440 px、12 fps、360 帧；体积优先：720 px、8 fps、180 帧。宽度不放大小范围画面。
- app 默认均衡，替代之前沿用 CLI 的 900 px 默认。CLI 独立使用仍保持原默认，不读 app 设置。
- 提示音和导出后在访达中显示 GIF 可分别关闭，默认开启。
- 开始录制时快照设置，当前录制期间的修改从下一次生效，避免结束后突然保存到不同文件夹。快捷键沿用立即生效方式。
- CLI 与 app 版本均为 1.5.0。增加启动参数 --settings，以及已运行 app 再打开时显示设置的入口。

## 当前验证

- `npm test`：14/14 通过，含新增的真实 ffmpeg 画质尺寸检查。1920×1080 源在三档宽度参数下分别产出 1920×1080、1440×810、720×406 GIF；160×120 小画面不会被放大。
- `npm run test:native`：10/10 通过，含默认值、旧目录迁移、不写入默认值、持久化重载、录制设置快照，以及导出参数和框选不裁剪检查。设置测试使用内存存储，没有写用户偏好。
- `./native/build.sh`、`codesign --verify --strict`、Info.plist 校验、`git diff --check` 通过。
- 使用实际 AppSettingsView 和 AppKit 控件离屏渲染并查看 1020×1220 预览，各分组、三个快捷键、两个开关、底部说明均未被截断。预览保存在 `screenshots/settings.png`。这不是运行中窗口的截图。
- 已重启到本次构建的 app，进程以 --settings 参数运行。
