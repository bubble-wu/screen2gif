# 1.4.0 修复与验证

2026-10-07。采用用户选定的 A「取景框」，修复首次审查列出的 R1–R9。

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| R1 快速最终状态丢失 | 先提取变化，再抽样；保留最终状态 | 快速黑白切换、仅最后一帧变化，检查成片像素 |
| R2 开头运动被裁掉 | cropdetect 显式 skip=0；裁剪用抽样前的完整变化序列 | 开头/结尾分离区域、仅一次变化、全静止视频 |
| R3 旧回调影响新录制 | MainActor 统一管理；每次录制独立 id；output 身份校验；超时先失效再清理 | 新旧 session 交错、重复完成、启动取消测试 |
| R4 限帧丢结尾 | 均匀抽样包含首尾；上限 1 明确保留最终状态 | 三色视频上限 1/2，检查最终像素 |
| R5 JSON stdout 被污染 | --json/-q 下子命令 stdout 转 stderr | 模拟采集，执行有 stdout 的子命令并解析结果 |
| R6 系统版本不一致 | Info.plist 与两条编译分支统一 macOS 15 | 编译通过，Mach-O minos=15.0 |
| R7 提前提示开录 | 等 SCRecordingOutput 的 didStart 和对焦完成，再启用 REC、计时及提示音；准备中可取消 | 会话状态测试；实际 SDK didStart → 采集 → 停止路径通过 |
| R8 超时清理无上限 | 取消/超时立即使 session 失效；停止清理独立执行，最多等待 5 秒 | 不响应的操作触发 deadline、取消立即返回、迟到结果不重复 resume |
| R9 框选窗口引用环 | 弱捕获，完成时清空回调/视图/窗口所有者 | 创建并 Esc 取消 20 次，逐次断言窗口和视图释放 |

同时处理了报告中的其他完善项：零坐标及奇数尺寸裁剪边界、ready-file 预检不碰正式信号文件、JSON 的成品统计与逻辑关键帧数分开、CLI 与 lib 内置进 app。调色板中间文件移到私有工作目录，避免覆盖输出旁的同名文件；concat 支持带单引号的路径，采用 100 Hz 时间基。
